This project uses data analytics and machine learning techniques to analyze retail store performance, identify sales patterns, segment stores, discover department-level associations, and forecast future sales.

The primary objective is to help retail businesses improve store performance, increase sales, optimize inventory, and make more informed business decisions using historical sales and operational data.

The analysis covers 45 stores and their department-level weekly sales, along with information about store characteristics, economic indicators, holidays, and promotional markdowns.
